# 文献价值分级标准（按本课题选题定制）

**用途**：检索到几十上百条结果时，用它决定「哪些必读、哪些留存、哪些只给链接、哪些直接排除」。
**原则**：不是"相关就下"，而是"能为哪一条论证服务"。没有归属的文献，再好也只是背景。

## 0. 课题坐标（判断基准，改课题就改这里）

- **对象**：杀爆（破片杀伤）战斗部打击下的**舰船甲板类结构**（甲板 / 加筋板 / 夹层板 / 板架）
- **载荷**：冲击波 + 破片**两种毁伤元耦合**（不是单独冲击波、也不是单独侵彻）
- **方法**：机器学习**代理模型**快速预测毁伤，替代逐次数值仿真
- **四个创新点**
  1. **耦合机理**：联合作用 ≠ 两者线性叠加，要给出耦合系数/非线性增量
  2. **物理约束 / PIML**：把量纲、守恒、经验公式嵌进模型，改善外推
  3. **多保真 + 主动学习**：低保真仿真 + 少量试验/高保真，样本效率优先
  4. **代理模型反哺经验公式**：用模型修正/生成工程可用的显式公式

## 1. 四级分类

| 级 | 定义 | 处置 |
|---|---|---|
| **A 核心** | 直接回答四个创新点之一，缺了会被审稿人问"你凭什么" | 必下必读，进 `文献/`，写进开题 |
| **B 支撑** | 方法或现象可迁移，但对象/载荷不完全一致 | 下载留存，读方法与结论段 |
| **C 背景** | 提供领域全景或工程背景，不直接支撑论证 | **只给链接+题录**，不下载全文 |
| **D 排除** | 与对象、载荷、方法三者都不搭 | 不记录 |

## 2. 判定规则（按顺序套，命中即停）

### 评 A（核心）——必须同时满足
1. **载荷**：标题/摘要出现 combined / simultaneous / synergistic / 联合 / 耦合 + blast / explosion / 冲击波 与 fragment / 破片（两个毁伤元都在）
2. **对象**：plate / panel / deck / stiffened / sandwich / 甲板 / 加筋板 / 夹层板 / 板架
3. **贡献**：属于以下之一
   - 给出耦合载荷的量级、时序、相对贡献（创新点 1）
   - 明确论证"联合作用 > 线性叠加"（创新点 1）
   - 在爆炸/冲击领域用 ML/PIML 做毁伤或载荷预测（创新点 2）
   - 多保真 / 主动学习 / 序贯采样在冲击动力学中的应用（创新点 3）
   - 用数据驱动方式修正或生成工程经验公式（创新点 4）

### 评 B（支撑）
- 命中 (1)+(3) 但对象不是板类（RC 柱/梁、容器、整车）→ 方法可迁移
- 命中 (2)+(3) 但只有一个毁伤元（纯爆炸 or 纯侵彻）→ 结构响应可参照
- 不命中 (1)(2)，但属于**多保真/主动学习/贝叶斯优化**的通用方法学 → 创新点 3 的弹药库
- 综述类：主题对得上但年份较早，用于追溯奠基工作

### 评 C（背景）
- 只有战斗部/破片威力场/毁伤评估体系，没有结构响应与数据驱动
- 只有材料动态性能、装药、引战配合
- 主题正确但纯实验、无模型、且结论已被更近的综述覆盖

### 评 D（排除）
- 水下爆炸气泡脉动、舰船水下接触爆炸（载荷机理不同）
- 岩石爆破 / 拆除爆破 / 民用爆破（`coupling` 在此指"不耦合装药"，是最大的误检来源）
- 医学冲击伤、交通事故、风工程等仅在用词上重叠
- 纯数值算法（CFD/FEM 求解器改进）且不涉及毁伤预测

## 3. 判定时的三个硬约束

1. **"耦合"必须是真的耦合**：标题里同时有 blast 和 fragment 才看；只写 blast 的一律不能进 A。
2. **年份不对称**：A 级允许 2010 年后的奠基文献；B/C 级优先 2020 年后，除非是被反复引用的经典。
3. **中文与外文分开判**：中文库的"毁伤评估"多以战斗部效能为落点，不等于结构响应，别混进 A。

## 4. 输出格式

每条给出：`级别 | 题名 | 年 | 来源 | DOI/链接 | 归属创新点 | 一句话理由`

- A 级进「必读清单」，按创新点分组
- B 级进「备用清单」，按方法/对象分组
- C 级只进「链接清单」，不下载
- 汇报时明确说：`共 N 条，A=a / B=b / C=c / D 排除=d`

## 5. 自检问题（每次分级后问自己）

- 这批 A 级里，四个创新点各被几篇支撑？哪个创新点是 0 支撑？→ 0 支撑的那个要单独补检索。
- A 级有没有全是同一课题组的？→ 需要补其他团队，避免论据单一。
- 有没有"看起来很相关、但读完只给你一句背景"的？→ 降级，别占必读名额。
