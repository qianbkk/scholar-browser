# 文献价值分级标准（通用模板）

> **本文件是方法模板，不含任何具体课题信息。**
> 用法：把它复制成 `triage.local.md`（`.gitignore` 已排除，不会被公开），把 §0 换成你自己的课题坐标，§2 的判定规则按你的领域改写。**同目录存在 `triage.local.md` 时，优先读它，本模板只作参考。**

**用途**：检索到几十上百条结果时，用它决定「哪些必读、哪些留存、哪些只给链接、哪些直接排除」。
**原则**：不是"相关就下"，而是"能为哪一条论证服务"。没有归属的文献，再好也只是背景。

## 0. 课题坐标（占位，先填这里）

- **对象**：<研究对象，例：某类结构 / 材料 / 构件 / 系统>
- **载荷或工况**：<主载荷、耦合方式；写清"单一"还是"多因素联合">
- **方法**：<技术路线，例：数值仿真 / 试验 / 数据驱动 / 代理模型>
- **创新点（3–5 条，越具体越好）**
  1. <创新点 1>
  2. <创新点 2>
  3. <创新点 3>

> 填完这一节，"值不值得读"就从主观判断变成可核对的条件：每条文献要么命中某个创新点，要么不命中。

## 1. 四级分类

| 级 | 定义 | 处置 |
|---|---|---|
| **A 核心** | 直接回答某个创新点，缺了会被审稿人问"你凭什么" | 必下必读，进 `文献/`，写进正文 |
| **B 支撑** | 方法或现象可迁移，但对象/载荷不完全一致 | 下载留存，读方法与结论段 |
| **C 背景** | 提供领域全景或工程背景，不直接支撑论证 | **只给链接+题录**，不下载全文 |
| **D 排除** | 与对象、载荷、方法三者都不搭 | 不记录 |

## 2. 判定规则（按顺序套，命中即停）

### 先做关键词翻译

把 §0 的每一项翻译成**标题/摘要里会出现的可检词**，正例与反例都列：

| 课题要素 | 命中词（例） | 易误检词（必须排除） |
|---|---|---|
| 对象 | <同一概念的不同写法、中英文> | <同词不同义的领域> |
| 载荷/工况 | <该载荷的标准表述> | <字面相同但机理不同的场景> |
| 方法 | <方法名及其变体> | <方法名在别的学科的含义> |

> 这张表是分级规则的地基。**没有它，A/B/C/D 只是感觉。**

### 评 A（核心）——必须同时满足

1. **要素齐全**：标题/摘要同时出现"对象"与"载荷"（若是耦合问题，**两个因素都要在**）
2. **贡献对得上**：属于 §0 创新点之一——给出机理/量级/时序证据、提出新方法、验证外推能力、产出可用的工程结论
3. **不是背景综述**：综述只在它系统梳理了你要用的方法脉络时才升 A

### 评 B（支撑）

- 命中"载荷+贡献"但对象换了 → 方法可迁移
- 命中"对象+贡献"但只有单一因素 → 结构响应可参照
- 不命中对象/载荷，但属于你需要的**通用方法学**（优化、采样、不确定性量化）→ 方法弹药库
- 早年综述：主题对得上，用于追溯奠基工作

### 评 C（背景）

- 只有工程背景、体系框架、政策标准，没有结构响应或数据
- 只有材料/工艺/参数，不涉及你的工况
- 主题正确但纯实验、无模型，且结论已被更新的综述覆盖

### 评 D（排除）

- **同词不同义**的领域（最高频误检来源，务必在 §2 关键词表里列清）
- 机理不同：载荷类型、时间尺度、边界条件不一致
- 纯求解器/算法改进，与你的预测目标无关
- 医学、交通、土木等仅在用词上重叠的研究

## 3. 判定时的三个硬约束

1. **耦合必须是真的耦合**：只有标题里两个因素同时出现才进 A；"顺带提到"的一律降级。
2. **年份不对称**：A 级允许较早的奠基文献；B/C 优先近五年，除非是被反复引用的经典。
3. **中文与外文分开判**：中文库的"评估/预测"常以工程效能为落点，不等于机理或模型，不要混进 A。

## 4. 输出格式

每条给出：`级别 | 题名 | 年 | 来源 | DOI/链接 | 归属创新点 | 一句话理由`

- A 级进「必读清单」，按创新点分组
- B 级进「备用清单」，按方法/对象分组
- C 级只进「链接清单」，不下载
- 汇报时明确说：`共 N 条，A=a / B=b / C=c / D 排除=d`

## 5. 自检问题（每次分级后问自己）

- 这批 A 级里，每个创新点各被几篇支撑？哪个是 0 支撑？→ 0 支撑的要单独补检索。
- A 级有没有全是同一课题组的？→ 需要补其他团队，避免论据单一。
- 有没有"看起来很相关、但读完只给你一句背景"的？→ 降级，别占必读名额。
- 关键词表里的"易误检词"这轮有没有真的出现？→ 出现就把规则写死，别每次重判。
