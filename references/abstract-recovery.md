# 摘要回填（L1.6）：全文拿不到时，怎么把「主要内容」拿到手

> 读这份的时机：**全文下不来，但不能只回一句"下不了"**；或者手上已有一份清单，其中若干条只有题录。
> 本文所有结论来自 2026-11-16 / 11-18 两轮实测（67 条待补 → 67 条补齐），不是推测。

## 1. 铁律

1. **"取不到摘要"多数不是权限问题，是路径问题**。先换入口，再谈登录态。
2. **每条摘要都要标来源**（出版商页面实测 / 开放图谱 / 中文镜像）。转述不算，转述会失真。
3. **DOI、卷期、页码一律从已核验清单取，不凭印象写**。凭印象写 DOI 是这类任务最容易犯且最丢人的错。
4. 摘要拿到 ≠ 全文拿到。**交付时要把这两件事分开说**，否则用户会以为能引用全文。

## 2. 通道优先级（按实测命中率排）

| 序 | 通道 | 实测命中 | 适用 | 备注 |
|---|---|---|---|---|
| 1 | **出版商/期刊落地页**（带渲染的抓取） | 42/42 | Elsevier、Springer、SSRN、中文期刊官网 | 首选，摘要是原文，还带关键词、卷期 |
| 2 | **中文镜像站**（百度学术 / 维普高校镜像 / 掌桥 / CNKI 移动端） | 4/4 | 中文学位论文、中文期刊 | 见 §4 |
| 3 | **出版商 RIS 导出** → `ris_meta.py` | 25/25 | ScienceDirect 批量 | 最全最准，但要先能点导出 |
| 4 | OpenAlex `abstract_inverted_index` | 12/67 | 英文，按 DOI 直查 | 倒排索引需重建拼句 |
| 5 | Semantic Scholar | 4/67 | 英文 | 无 key 极易 429，退避一次即跳过，不要刷 |
| 6 | Crossref | 少 | 有 JATS 摘要的刊 | **Elsevier 基本不入库摘要**，别指望 |

**结论**：英文走 1 → 4 → 5 → 6；中文走 1 → 2。**不要把 OpenAlex/Crossref 当主力**——它们只能覆盖一小半，且对订阅刊最不友好。

## 3. 英文：从 DOI 到摘要页

```
DOI → https://doi.org/<DOI> → 302 → linkinghub.elsevier.com/retrieve/pii/<PII>
    → https://www.sciencedirect.com/science/article/abs/pii/<PII>
```

- **正则取 PII** 比反复走 doi 跳转稳：`pii/([A-Z0-9]{10,})`。
- 拿到 PII 后先批量解析好、再逐页取摘要，可避免重复跳转导致的超时。
- Springer 章节页（`link.springer.com/chapter/...`）、SSRN（`papers.ssrn.com`）直接给 Abstract，无需跳转。

### 访问控制实测（2026-11）

| 目标 | 本机 curl / urllib | 带渲染抓取 |
|---|---|---|
| `sciencedirect.com/science/article/...` | **403**（尾部 800 KB 拦截页） | ✓ |
| `doi.org` | 200 但只是跳转壳（~2.7 KB） | ✓ |
| `link.springer.com` | ✓ | ✓ |
| `papers.ssrn.com` | 视 cookie | ✓ |
| `r.jina.ai` 文本代理 | **连不上**（exit 7） | ✗ |

**推论**：摘要是"渲染后才有"的内容，脚本层 curl 只能拿到壳。**L1.6 属于 AI 侧动作，不是 `oa_fetch.py` 能干的活**，别硬塞进脚本。

## 4. 中文：四条能出摘要的入口

| 入口 | URL 形态 | 给什么 | 实测 |
|---|---|---|---|
| 期刊官网文章页 | 见 `platforms-cn-journal.md` | 题录 + 中英文摘要 + 关键词 | ✓ 郑州大学学报、兵器装备工程学报 |
| 知网 DOI 解析 | `link.cnki.net/doi/<DOI>` | 中文摘要全文 + 关键词 + 基金 | ✓ 建筑结构学报 |
| 知网学位论文 | `cdmd.cnki.com.cn/Article/CDMD-<校代码>-<id>.htm` | 摘要（页面节选，末尾常带 `...`） | ✓ 沈理工 10144、哈工程 10217 |
| 镜像站 | 百度学术 `a.xueshu.baidu.com/usercenter/paper/show?paperid=...`<br>维普高校镜像 `*.smart.vipslib.com` / `lib.*.edu.cn/articlesearch/web_searchingDetail?id=...` | 完整摘要（常转载万方/维普全文摘要） | ✓ 4/4 |

**校代码速查（实测确认）**：沈阳理工大学 `10144`、哈尔滨工程大学 `10217`。其余按 `CDMD-<校代码>-<论文id>` 试，校代码可在知网学位导航页查。

### 中文站的坑

| 站点 | 现象 | 应对 |
|---|---|---|
| `s.wanfangdata.com.cn`、`d.wanfangdata.com.cn` | 滑块 / 真人验证，渲染抓取也过不去 | 换百度学术镜像（往往一字不差转载） |
| `mall.cnki.net` | 403 Forbidden（openresty） | 换 `link.cnki.net` / `cdmd.cnki.com.cn` |
| `search.cnki.com.cn` | JS 空壳，结果区"加载中" | 不要指望检索页，直接猜 cdmd 详情页 |
| 高校图书馆门户 | 详情页是 JS 壳，直接抓只返回"统一检索" | **用搜索引擎收录的正文片段**（见 §5） |
| 期刊旧投稿域名（如 `scbg.qks.<校>.edu.cn`） | 只剩导航，或 `202` 挑战页 | 核实现官网域名（如 `bzxb.cqut.edu.cn`） |

## 5. 三条"反直觉但有效"的打法

1. **搜索引擎片段拼摘要**。中文镜像页是 JS 壳，但搜索引擎已收录正文。用**不同关键词切片**检索同一篇，可把摘要的不同段落分别钓出来，拼成完整版。实测：一篇硕士论文分两次检索拼全了三段。
2. **先核实期刊官网域名**。同一刊常有"旧投稿系统 + 现官网"两套域名，旧域名详情页往往失效。判据：页面里有 DOI、卷期、`免费阅读PDF` 按钮的才是现官网。
3. **正文里搜"摘要:"而不是找 `#abstract`**。中文页面结构不统一，`<meta name="description">` 与 `citation_abstract` 常为空；直接抓正文文本再正则 `摘\s*要[:：]` 更稳。

## 6. 拿不到就是拿不到：怎么交代

有些页面是 **WAF 挑战**（返回 `HTTP 202` + 一段 JS），渲染抓取也过不去。实测：某刊 `download.aspx?type=paper&id=...`、`/html/<年期>/....html`、`/pdf/<年期>/....pdf` 三种都 202。

这时**不要反复重试**，按下面写清楚：

```
状态：摘要已取得（来源：<渠道>）；全文未取得
原因：站点 WAF 挑战（HTTP 202），程序化通道不可用
可动作：该页有「免费阅读PDF」，浏览器点开即可；或走文献传递
```

## 7. 交付格式（每条一段，缺一不可）

```
#### <序号> · <题名>
*<来源> <年>, <卷(期):页>* | `<DOI 或 库内标识>`
链接：<可打开 URL>

**主要内容**：<中文 2–4 句，含方法 + 关键结论/数字>
*摘要来源：<出版商页面实测 / 知网详情页 / 镜像站 / OpenAlex …>*
```

**「主要内容」不是摘要翻译**：要压成"它做了什么 + 用什么方法 + 关键数字/结论 + 对当前课题有什么用"。只抄摘要等于没做这一步。

## 8. 复现要点（脚本层能自动化的部分）

| 能做 | 不能做 |
|---|---|
| 按 DOI 批量查 OpenAlex / Crossref / S2 并落 JSON | 打开 ScienceDirect 摘要页（直接请求被 403 拦下） |
| 解析 DOI → PII 并缓存映射 | 过万方滑块 |
| 汇总成 Markdown（题录 + 摘要 + 来源） | 判断"这篇对我有没有用" |

脚本要点：并发 6 左右、每请求间隔 ≥0.12 s、S2 退避 1.2 s ×3 次即放弃、结果**增量写盘**（每 8 条落一次），否则中途被杀全丢。
