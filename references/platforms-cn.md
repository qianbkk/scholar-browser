## ★ 2026-11-15 重大更正：万方可以自动下载，且给真 PDF

上一版写「下载触发未验证」，2026-11-15 实测**完整跑通 12 篇**，结论如下：

| 项 | 实测值 |
|---|---|
| 下载结果 | **真 PDF**（`%PDF-1.4/1.6`），不是 KDH——这是万方相对知网的最大优势 |
| 按钮组坐标 | 1522×726 视口下 y≈600；`在线阅读`(x≈397) / **`下载`(x≈492)** / `全文快报`(x≈554) / `引用` / `收藏` |
| 点击效果 | 直落系统下载目录，无二次确认、不弹阅读器 |
| 单篇耗时 | 检索到落盘约 15–20 秒 |
| 权限判据 | 按钮区出现「下载」即可下；若只有「原文传递」= 该刊万方未购全文（如《建筑结构学报》） |

### 正确流程（照做，别自由发挥）

```
S1 tab_goto 直达结果页（最稳，免去输入框）：
   https://s.wanfangdata.com.cn/paper?q=<URL编码题名>&p=1
   —— 直连域即可，机构 IP 被识别；webvpn 亦可（见下）
S2 tab_screenshot 确认「找到 N 条」且首条题名 = 目标
S3 用 tab_screenshot 的 clip 小图定位按钮（clip x=340,y=570,w=620,h=70），
   确认「下载」真实 x 坐标后再点 —— 凭整屏目测必点偏
S4 cua_click(x≈492, y≈600) → 等 3–5 秒 → ls 下载目录核验 %PDF 魔数
S5 篇间留 3–5 秒；每篇只点一次
```

### 踩过的三个坑

1. **点错坐标**：第一次把 (1102,601) 当成下载按钮（那是右侧「被引/下载」计数区），第二次点 (438,601) 落在「在线阅读」与「下载」之间。**必须 clip 截图确认**。
2. **`cua_click` 偶发 `provider invocation timed out`**：这是抖动，不是站点阻塞。重新 `tab_goto` 聚焦后再点即可。**不要因此判定"万方不可脚本化"。**
3. **下载中转页会"复活"重新下载**（2026-11-16 实测，代价 154.6 MB）：每次点「下载」都会新开 `oss.wanfangdata.com.cn` 的「下载信息」中转页。这些页面留着不关，用户之后**一点开/切过去，JS 重新执行，整批 PDF 又下一遍**（浏览器自动加 `(1)` 后缀）。13 篇一次白下 154.6 MB，并重新计一次机构下载次数。
   → **收尾必须关掉所有 `oss.wanfangdata.com.cn` 标签**；按 `SKILL.md` §4「标签页会话管理」用基线比对清场。

### 下载文件里有什么（可核验的内部标记）

万方 PDF 尾部会追加一段明文追踪信息（`%%EOF` 之后），实测样例：
```
transferOut:FreeDefault.OAPeriodicalFulltext user:Group.<机构组> ClientIp:<IP> ServerIp:<IP> DateTime:2026-11-15 23:53:14 ...wftrace
```
- `FreeDefault.OAPeriodicalFulltext` = 该篇走**免费开放获取**通道；
- 这段尾巴是**每次下载都不同**的原因 → 同一篇文章重复下载，MD5 必不相同，**不能靠 MD5 判重**，要按题名+页数+首页文本判重。
- 顺带：这段尾巴会让 `pypdf` 报 `PdfStreamError: Stream has ended unexpectedly`（`%%EOF` 位置之后有垃圾数据）。文件本身**没坏**，用 PyMuPDF 可正常读出全部页与正文。**判完整性不要只用 pypdf**。

### 计费：按刊物分档，交易记录可直接读（2026-11-16 实测）

不要从 PDF 尾部或 URL 单字段猜，**每个「下载信息」中转页的 URL 里就带完整交易记录**（`transaction` 参数，URL 解码后是 JSON）。取到 12 条样本后确认：

| 情形 | 字段 | 含义 |
|---|---|---|
| 机构已购期刊 | `transferOut: {"GTimeLimit.<机构码>": 3.0}`、`turnover: 3.0` | **每篇扣 3.0 额度** |
| OA / 免费期刊 | `transferOut: {"FreeDefault.OAPeriodicalFulltext": 0.0}`、`turnover: 0.0` | **不扣** |
| 重复下载 | 同一 `fileId` 出现多条订单，`transaction.id` 不同 | **重复扣费** |

实操要点：
- **下每篇前确认目标，只点一次**。实测同一篇被连点两次 → 两条 3.0 订单。
- 想核对某次下载到底扣了多少：不要关标签，先 `tabs_claim` 读 URL，从 `transaction` 里取 `turnover` 和 `transferOut`，**再关**。标签一关就查不到了。
- 机构码形如 `<机构码>`（本校图书馆缩写），`userIP` 亦在记录中——这些是**机构侧凭据信息**，只用于本人自查扣费，**不要写进任何外传文档**。

### webvpn 路径（用户提供的补充通道）

本校 webvpn 形如：
```
https://webvpn.<学校域名>/https/<hash>/<path>
```
万方入口：
```
https://webvpn.<学校域名>/https/<hash>/index.html
```
- `<hash>` 是**目标域名的加密映射**，不同目标域 hash 不同，**不能拿万方的 hash 拼别的站**。
- 一般情况直连即有机构登录态；webvpn 仅作兜底。
- 常驻登录，Agent 可直接用，无需用户再操作。
- **换成自己的入口**：见 `limits.md` §1.0.4 的三步指引（门户登录 → 点进目标库 → 抄域名与 hash）；Skill 不保存这两个值。

## 通用提示

- 中文订阅库 → **不走 L2 直取**，直接 L3（`discovery.md` §4）。
- 机构登录态：优先校园网 / CARSI / 校外访问。**机构名不一定在首页显示**——维普只在 `qikan` 子站显示，万方在结果页右上角，首页可能只有「登录/注册」。不能以首页无机构名判授权失效。
- 权限判据：能显示「下载」才继续；显示"登录/购买/申请"即判无权限，不反复试探。
- 两站都有「引用 / 收藏 / 批量」类按钮 → **只观察不点击**。

## 首次操作某站的标准动作（避免瞎点）

1. `tab_goto` 到 entry → `tab_screenshot` 一屏，确认是真实页面（不是 challenge 页）。
2. `dom_cua_get_visible_dom` 定位输入框；**若快照超时或读不到控件，先判"该站不可脚本化"**，不要连续重试。
3. 输入按 `toolchain.md` §2 顺序试，**每次读回 `value`** 再提交。
4. 提交后截图确认结果页变了；普通跳转可用 `tab_url` 辅助，并**记下结果页 URL 形态**供回退。
5. 读题录用截图；确认权限标识后才考虑点下载；点一次，核验落盘。
6. 把实测到的字段回填本文件（主会话做），并升级等级。
